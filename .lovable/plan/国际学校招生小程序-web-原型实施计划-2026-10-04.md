# 国际学校招生小程序 Web 原型实施计划

## 目标
依据上传的 PRD 制作可交互、移动端优先的招生应用原型；以杜伦大学标志紫为主色，采用简洁、专业、英伦学院风视觉。当前项目为网页技术栈，因此先完整还原小程序的用户体验与核心流程，微信原生能力以网页中可验证的等价交互呈现。

## 本次实现
- 建立三个底部主入口：学校相关、海外留学、联系我们。
- 实现每日一次的主推项目弹窗，并支持跳转项目详情。
- 学校页包含学校介绍、师资力量、校园环境、学生访谈与官网入口。
- 留学页包含国际本科、硕士、本科直博分类，项目卡片、筛选与完整详情视图。
- 联系页包含意向表单、联系方式、AI Hub 工作室信息与预约到校流程。
- 增加全局咨询入口、成功反馈、名额状态和移动端适配。
- 使用 Lovable Cloud 保存意向线索与预约记录；内容展示先采用与 PRD 匹配的示例资料。

## 视觉方向
- 杜伦紫作为品牌主色，搭配纸白、石灰灰、深墨色与克制的金色点缀。
- 英伦学院刊物式排版：衬线标题、清晰网格、细线边框、少量纹章式细节。
- 不使用浮夸渐变或装饰气泡；图片聚焦真实校园、课堂和学生体验。
- 保持微信小程序式单手操作体验，同时在桌面端呈现居中的移动应用画布。

## 数据与安全
- 新建 `leads` 与 `bookings` 数据表，并配置仅允许公开提交、禁止公开读取的访问规则。
- 表单加入必填项、手机号、长度及人数校验。
- 未提供的学校名称、电话、邮箱、官网与首批项目资料会明确标为示例内容，避免伪装为真实信息。

## 验证
- 检查首页弹窗、三个主入口、项目筛选/详情、意向提交与预约提交。
- 检查手机和桌面显示、内容无重叠、表单反馈与当前构建状态。

## 技术说明
- 使用现有 TanStack Start + React + Tailwind 架构。
- 微信客服、手机号授权、订阅消息、地图、拨号和 web-view 等原生接口，在此网页预览中使用明确的模拟反馈或标准网页链接；正式发布为微信原生小程序时需再接入微信主体、业务域名和客服资质。
