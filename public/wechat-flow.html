招生小程序：从开发到上线流程

页面用 Lovable / Cursor 做；小程序只做一个壳去打开网页；数据和微信能力走腾讯云开发。 不是把整份网页代码翻译成小程序页面。

乙方（你）负责 甲方负责 两边一起 正式上线结构
阶段 1现在就能做
乙方

1. 改界面

在 Lovable 或 Cursor 里改学校介绍、项目、表单等页面。代码在 GitHub 仓库的 src/。

乙方

2. 浏览器里预览

打开 Demo / 预览网址，点页面、填表、看交互。这一步还不需要微信开发者工具。

甲方

3. 准备资质

  • 小程序 AppID
  • 把你加成开发者
  • 备案域名
  • 同意开通云开发
↓
阶段 2接到微信里
乙方

发布网页

把 Lovable 做好的页面发布成 https 网址（甲方备案域名，或云开发静态托管）。

→
一起

配置业务域名

在微信公众平台把该域名加入业务域名，并放好校验文件。否则小程序打不开网页。

→
乙方

打开小程序壳

微信开发者工具只导入仓库里的 miniprogram/，把 h5Url 填成上面的网址。

↓
阶段 3正式运行结构

用户打开小程序

看到的是微信里的入口、标题栏、权限弹窗。

→

壳加载网址

web-view 打开你的 https 页面。房间装修仍是 Lovable 做的那套。

→

数据和微信能力

线索 / 预约进腾讯云开发；手机号、订阅消息、客服用 wx 接口。

界面放哪？

https 网页（Lovable / Cursor 维护，GitHub 同步）

数据放哪？

甲方的腾讯云开发（数据库、云函数）

敏感能力放哪？

小程序原生能力：登录、手机号、订阅消息、客服

↓
阶段 4上线前检查
甲方

合规与支付

  • 类目与资质
  • 隐私保护指引
  • 云开发付费（正式发布后）
  • 客服与订阅消息模板
乙方

联调与提交

  • 真机预览填表 / 预约
  • 确认域名与云开发白名单
  • 协助上传代码
甲方管理员

审核发布

管理员在微信公众平台提交审核并发布。之后用户搜索 / 扫码就能用。

不要这样做：把整个 GitHub 仓库导入微信开发者工具。
要这样做：网页继续在 Lovable / Cursor 改；微信工具只打开 miniprogram/ 这个壳；正式数据放云开发。
